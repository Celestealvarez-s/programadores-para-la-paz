Sistema operativo: Es el entorno donde se ejecuta el servidor. Permite administrar los recursos del hardware y ejecutar procesos.

Node.js: Es el entorno que permite ejecutar JavaScript en el servidor y construir aplicaciones backend.

Aplicación server.js: Es el archivo principal donde se define el comportamiento del servidor y las rutas.

Puerto: Es el canal por donde el servidor escucha solicitudes. En este caso se usa el puerto 3000.

Logs: Son registros que muestran la actividad del servidor, como mensajes de inicio, errores o eventos importantes.
