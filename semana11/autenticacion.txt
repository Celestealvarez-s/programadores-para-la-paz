El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando un nombre de usuario y una contraseña. Esto permite verificar su identidad antes de acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. De esta manera se evita que personas no autorizadas accedan al sistema. No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, claves de API, tokens ni otros datos sensibles de la comunidad.
